I'm a big fan of browsers like Brave and Aloha that push the envelope with what's possible on Android. But the one feature I always wished they had on Android was support for extensions from the Chrome Web Store.

The Firefox app for Android offers a decent implementation of extensions, but it is sometimes unreliable.

But after a little research, I found a lightweight Firefox fork that supports extensions and runs nearly flawlessly on Android.

I found it on Iceraven's official [GitHub](https://github.com/fork-maintainers/iceraven-browser) and tested it for myself. Needless to say, I was impressed.

Iceraven's extension library is expansive and includes all the major extensions I like to use. From uBlock Origin to Keepa to Bitwarden, the browser supports all the essentials.

Iceraven delivered the desktop-class experience I was looking for.

Not every extension from the Chrome Web Store works properly. Some rely on desktop APIs that don't work well on phones. But the ones highlighted in Iceraven work like a charm.

For privacy-sensitive users like me, Iceraven gives you access to tools such as ClearURLs and Privacy Badger.

Do you like to use Dark Mode on every website? The Dark Reader extension is available.

But my favorite quality-of-life extension I use in Iceraven is Video Background Play Fix.

The background fix extension lets me play YouTube videos in the background, similar to what Brave does.

I found installing extensions in Iceraven straightforward, and it only took me a few seconds.

To install or add new extensions in Iceraven, here are the steps I followed:

1. Tap the **three-dot menu** in the upper-right corner.
2. Tap the **Extensions** tab in the pop-up menu.
3. Install the Extensions from the lengthy list that pops up.

If there are other extensions I want to install that aren't on the list, I only need to download the .xpi file to my phone's internal storage.

I followed the first two steps mentioned above, then tapped the **puzzle piece icon** in the upper-right corner. This let me import the .xpi file and install the extension I needed.

Not every extension works as intended in Iceraven, especially the obscure ones I sideloaded.

Since Iceraven is a fork of Firefox, it offers other essential features a modern browser is expected to have.

I can sync my browsing history and bookmarks, manage passwords, and customize basic gestures.

And if I want to make deeper configuration changes, I can type **about:config** in the address bar and change settings to suit my preferences.

Iceraven also has a feature I've seen in the [Arc Search browser,](https://www.androidpolice.com/arc-search-browser-chrome-alternative/) albeit more effective. The browser can suspend tabs to avoid one of Android's most annoying features.

Android has an aggressive LMK (Low Memory Killer) feature that tends to crash or force-close apps when the system RAM is running low.

Iceraven suspends inactive background tabs to prevent force-closures or abrupt page reloads when this happens.

## You need to have faith to run Iceraven on Android

### An uncertain future

![Iceraven browser homepage on phone screen](https://static0.anpoimages.com/wordpress/wp-content/uploads/wm/2026/08/iceraven-icon-phone-screen.jpg?q=49&fit=crop&w=500&dpr=2)

Iceraven is still being actively developed, with frequent updates. But it would be irresponsible not to point out some of the downsides.

Iceraven can only be sideloaded from the GitHub repository or F-Droid, which might not be ideal for users who rely on Google Play.

While [sideloading apps on Android](https://www.androidpolice.com/googles-new-android-sideloading-rules-arriving-early-power-users/) is straightforward, Google's new rules might be problematic soon.

Iceraven's developers have refused to verify their identities with Google, which means sideloading the app may not be possible in the near future.

Unless Google reverses its decision, this will be the status quo for a while.

I've already mentioned that not every extension works as desired, so expect a good deal of trial and error when testing extension compatibility.

I also noticed that certain websites designed with Chromium in mind tend to be finicky.

Iceraven developers have ironed out these issues over time, but some websites don't behave the same way in Iceraven as they do in other browsers.

Finally, since Iceraven is a fork of Firefox, Iceraven occasionally takes slightly longer to incorporate Firefox's latest security and bug fixes.

If you plan to use Iceraven as your daily driver, keep a few things in mind before switching.

I use Iceraven alongside Aloha or Brave, especially when I need an extension like Keepa on certain websites that aren't available on either.

## Iceraven excels at emulating a desktop browser experience

Iceraven is a breath of fresh air amongst all the [Chromium browsers](https://www.androidpolice.com/i-used-google-chrome-for-14-years-but-this-browser-made-me-switch/) I've tested.

Its extension library is impressive and gives me the same level of control I have in desktop browsers.

It is the closest thing to a desktop-class experience while also having all the essentials.

The only thing keeping me from making it my daily driver is its uncertain future, but until then, I will enjoy my favorite extensions on my phone.
