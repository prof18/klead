CHIP auf Google bevorzugen
Discord ist ein spannendes Kommunikations-Werkzeug, das Software wie Skype und Teamspeak das Fürchten lehren möchte. Die Freeware erlaubt es, unkompliziert über einen Desktop-Client oder direkt über den Browser miteinander zu chatten oder sich per Audio/Video zu unterhalten.

Discord zum kostenlosen Download: Must-have für alle Gamer


Discord ist neben Teamspeak schon seit Jahren in der Gaming-Szene der Quasi-Standard, wenn es um Kommunikation während des Spielens geht. Mittlerweile - spätestens seit Corona - wird die Software aber auch von vielen Nutzern verwendet, die mit Games nichts am Hut haben.

Discord bietet mit seinen Servern umfangreiche Optionen, Raum-Strukturen anzulegen. Wer einen eigenen Server öffnet, kann beliebig viele Audio- und Textchannels öffnen, Bots für zusätzliche Funktionen nutzen und sogar eigene Emoji hochladen. Bis zu zehn Personen können sich außerdem live per Videochat unterhalten. Herausragend sind die Möglichkeiten von Discord, den Inhalt des eigenen Bildschirms an Freunde und Kollegen zu streamen - das klappt zuverlässig, nahezu ruckelfrei und selbst dann, wenn das Fenster im Hintergrund liegt.
ANZEIGE

Discord: Direkt im Browser nutzbar

Ein starkes Feature von Discord ist, dass die Software direkt im Browser benutzbar ist. So können Sie etwa Freunde und Bekannte via E-Mail auf Ihren Server einladen, den diese ohne das Programm zu installieren betreten können. Und mit den Apps für Android und iOS haben Sie das Tool auch auf dem Smartphone immer mit dabei.

Außerdem verfügt Discord über ein In-game Overlay, sodass Sie sich die GUI des Programms während des Spielens einblenden lassen können.

Was brauche ich für Discord?

Wenn Sie an Video- oder Sprachanrufen teilnehmen wollen, benötigen Sie ein Mikrofon und ggf. eine Webcam. Sollten Sie einen Laptop nutzen, können Sie hierfür das eingebaute verwenden. Für Standrechner oder wenn Sie eine bessere Tonqualität haben wollen, empfehlen wir ein Headset. Außerdem müssen Sie sich einen kostenlosen Account erstellen.
ANZEIGE

Wie tritt man einen Discord Server bei?

Am unteren Ende der linken Leiste finden Sie einen Plus-Button. Wenn Sie diesen drücken, können Sie entweder einen eigenen Server erstellen oder über einen Einladungs-Link einem bestehenden beitreten. Alternativ können Sie über den Lupen-Button nach Servern per Schlagwort suchen oder einen Einladungs-Link direkt im Browser aufrufen.

Wie sicher ist Discord?

Bei der Nutzung von Discord werden Daten wie IP-Adresse, Geräte ID, E-Mail-Adresse, Bilder, Nachrichten und Co. gesammelt. Da diese aber ausschließlich über die hauseigenen Server laufen, werden diese sensitiven Informationen an keiner Stelle offengelegt. Ende-zu-Ende-Verschlüsselung bietet der Dienst bisher aber nicht.

Was ist Discord Nitro?

Dicord Nitro wurde 2017 eingeführt und ist die kostenpflichtige Premium-Variante des Programms. Für 10 Dollar pro Monat - oder 99,99 Dollar im Jahr - dürfen sich Nitro-Nutzer über Vorteile wie individuelle Tags, animierte Emojis, höhere Videoqualität bei Streams und ein erhöhtes Uploadlimit freuen.

CHIP Fazit zu Discord

Discord hinterlässt einen großartigen Eindruck und sollte auf keinem Gaming-PC fehlen. Die Einrichtung des ausgereiften Kommunikations-Tools funktioniert unkompliziert, die Bedienung intuitiv. Toll ist, dass sich die Freeware direkt über den Browser bedienen lässt.
